FAQ

Questions about AI Loss Prevention

Do customers need to be identified?

No. We detect actions and items, not identities. Facial recognition is off by default and only considered where it's lawful and proportionate.

Will it slow down checkout?

No. Detection runs in parallel; on-screen prompts appear only when an item looks unscanned.

Which POS systems do you support?

We integrate with major POS vendors and any system that can export transaction events in near real time.

How do you measure results?

Pilots compare loss per lane against control stores, alongside alert precision and customer complaints.
